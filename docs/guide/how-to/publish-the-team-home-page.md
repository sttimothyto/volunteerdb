# Publish the team home page

Give your team a public web page, written in a Google Doc, that anyone can read without a sign-in.

## Before you start

- You are signed in as a leader, second-in-command or core team member of the team.
- You have a Google Doc with the content of the page: rehearsal times, contact points, sign-up links.
- Put nothing private in the doc. The page is exactly as public as the doc.

## Steps

1. In Google Docs, share the doc so that anyone with the link can view it.
2. Copy the link of the doc. It starts with `https://docs.google.com/document/d/`.
3. Open *Teams* and click the team.
4. Under *Volunteer home page*, click *Set home page doc*.
5. Paste the link into *Google Doc link*.
6. Click *Save*.
7. Click *Fetch now*.

## What you see

- After *Save*, the section shows a *Google Doc* link, *Fetch now* and *Change*.
- Until the first fetch it says *Not published yet — Fetch now downloads the doc, or wait for the nightly refresh (3:00).*
- After *Fetch now*, the page shows *Home page updated*, and a *Public page* link appears. Click it to see the result.
- The page lives under `/ministries/` on the site. *View Team Homepages* on the *Teams* page lists every published team.
- Every night at 3:00 the site fetches the doc again, so an edit in the doc appears the next morning. Click *Fetch now* to publish an edit at once.
- The section shows *Refreshed nightly · last fetched* with the date and time.
- A member who cannot edit the page sees a *View public homepage* button on the team page instead.

## Print a QR code

1. Click *Download QR Code to Public page*.
2. Print the image on a bulletin, a poster or a handout.

The code holds the address of the page. If the team is renamed or moved under another team, the address changes. Print a new code then.

## Take the page down

1. Click *Change*.
2. Click *Clear*.

## If something goes wrong

- If the message says *not a Google Doc link*, copy the link from the address bar of the browser while the doc is open.
- If it says *the doc is not publicly accessible (Google redirected to a sign-in page)*, repeat step 1.
- If the section says *Last fetch failed:* with a reason, the last good version stays published. Fix the doc and click *Fetch now*.
- If it says the doc is over 30 MB, or the text over 2 MB, make the doc smaller. A page holds up to 30 images of 5 MB each.
