# Cancel an event

Call off an event and tell everyone who signed up.

## Before you start

- You are signed in as a leader or second-in-command of the team of the event.
- Be sure. A cancelled event cannot be brought back; you would create it again.

## Steps

1. Open *Events* and click the event.
2. Click *Cancel event*, at the top right of the page.
3. Read the question: *Cancel this event? Everyone signed up is emailed, and open substitute requests are closed with it.*
4. Click *Yes, cancel it*. *Keep it* closes the question and changes nothing.

## What you see

- The page reloads with a *Cancelled* badge next to the name of the event. *Edit* and *Cancel event* are gone.
- Everyone who held a shift and has an email address gets a message. Its subject is *Cancelled:* and the title of the event. It says no action is needed.
- If the event was already over, nobody is emailed.
- Open substitute requests on the event are closed.
- The event leaves *Upcoming events*. *Show past* on *Events* still lists it, with *(cancelled)* after the title.
- If the parish has a public Google calendar, the event leaves it within 30 minutes.
- Sign-ups stay as history, but the event counts for nobody's service hours.
- A weekly repeat is a set of separate events. This cancels 1 week only; cancel each week you need to.
- If the event had a task force, the site removes that temporary team within 1 hour.

## If something goes wrong

- If the page says *event is already cancelled*, somebody else got there first. Reload the page.
- If you see no *Cancel event* button, the event is already cancelled, or you do not manage its team.
